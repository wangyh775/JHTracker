# AI 智能体公司清单生成 Prompt

> 把本 Prompt 复制到任何**带联网搜索**的 AI 智能体（ChatGPT with browsing / Claude / DeepSeek / Kimi / 智谱清言 / 文心一言 等），填入你的背景信息，AI 会深度检索网络并生成符合 JHTracker 导入格式的公司清单。

---

## 使用方法

1. 复制下方 Prompt 模板
2. 把 `{{候选人背景}}` / `{{目标岗位}}` / `{{目标城市}}` / `{{目标行业}}` 替换为你自己的信息（可参考 `prompts/profile.example.md`）
3. 粘贴到 AI 智能体对话框
4. AI 返回 Markdown 表格后，保存为 `career_data/企业清单_X_xxx.md`（X 为 A/B/C...）
5. 在 JHTracker 的「数据导入」页面点击导入

---

## Prompt 模板

```
你是一位资深的行业猎头与求职顾问。请基于以下候选人背景，深度检索网络，生成一份高质量的目标公司清单。

## 候选人背景
{{候选人背景}}

## 目标岗位
{{目标岗位}}

## 目标城市
{{目标城市}}

## 目标行业（可多选）
{{目标行业}}

## 任务要求

1. **深度检索**：联网搜索以下来源
   - 各公司官网招聘页、BOSS直聘、猎聘、拉勾、智联
   - 行业协会、产业研究院、链企智库等公司名录
   - 知乎/脉脉/小红书的求职经验帖
   - 招聘平台 2026/2027 校招专题

2. **公司筛选标准**
   - 必须在候选人目标城市有研发/技术岗位
   - 岗位方向与候选人技能匹配（核心技能覆盖、行业相关、职能契合）
   - 优先列出有明确校招计划的公司
   - 覆盖从头部大厂到细分领域隐形冠军
   - 数量：每个行业 30-60 家，总计 150-300 家

3. **匹配度评估**：对每家公司，简明说明为什么匹配候选人（一句话，结合候选人的具体技能点）

4. **输出格式**：严格使用以下 Markdown 表格格式，不要省略任何列

| 序号 | 公司名称 | 细分行业 | 城市 | 岗位方向 | 匹配理由 |
|:---:|:---------|:---------|:-----|:---------|:---------|
| 1 | **公司全称** | 细分领域 | 城市（多个用/分隔） | 自动化/机电/嵌入式/控制算法等 | 一句话匹配理由，引用候选人具体技能 |
| 2 | ... | ... | ... | ... | ... |

5. **行业分组**：按行业分多个表格，每个表格前用 `## 一、行业名（共X家）` 作为标题

6. **质量要求**：
   - 公司名用 **加粗**，必须用全称（如「汇川技术」而非「汇川」）
   - 城市只写目标城市，多城市用 / 分隔（如「北京/上海」）
   - 匹配理由要具体，避免空话（如「PID 控制经验匹配伺服驱动岗位」而非「公司很好」）
   - 同一集团下多个子公司可分别列出

请开始检索并生成清单。
```

## 文件命名规则

保存到 `career_data/` 目录时，文件名建议：
- `企业清单_A_工业自动化_能源_半导体_汽车.md`
- `企业清单_B_机器人_3D打印_高端装备_消费电子.md`
- `企业清单_C_医疗_航空航天.md`

JHTracker 导入时会自动识别文件名中的行业关键字，也可以通过「数据导入」页选择清单 A/B。
