## Purpose

Provides a user-facing Decision Inbox UI and REST API for reviewing, approving, modifying, and rejecting job recommendation proposals generated by AI Agents.

## ADDED Requirements

### Requirement: Decision Inbox API Endpoint
The system SHALL expose REST API endpoints to fetch job applications in `Pending Approval` status alongside their AI evaluation brief and recommendation score.

#### Scenario: User queries pending decision proposals
- **WHEN** a GET request is made to `/api/agent/decisions/pending`
- **THEN** the system SHALL return a JSON list of pending applications containing `application_id`, `company_name`, `position`, `match_score`, `agent_reason`, and `resume_id`.

### Requirement: Decision Action Endpoint
The system SHALL expose a REST API endpoint to accept human decisions (`approve`, `reject`, `edit`) on a pending application proposal.

#### Scenario: User approves a pending proposal
- **WHEN** a POST request is made to `/api/agent/decisions/<application_id>` with action `approve`
- **THEN** the system SHALL update the application status to `Applied` and record a positive `DecisionFeedback` entry.

#### Scenario: User rejects a pending proposal with reason
- **WHEN** a POST request is made to `/api/agent/decisions/<application_id>` with action `reject` and `reason` text
- **THEN** the system SHALL update the application status to `Rejected`, record a negative `DecisionFeedback` entry, and trigger a memory rule update.
