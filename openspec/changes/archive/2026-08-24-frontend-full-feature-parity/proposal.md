# Proposal: Frontend Full Feature Parity & Knowledge System Migration

## Why

While the architecture v2.0 Monorepo and async backend provide high performance and CDP automation, the current Vue 3 SPA frontend currently only implements a simplified Kanban view. The legacy Jinja2 codebase contained 22 mature recruitment intelligence templates (AI Daily Briefings, Timeout Warnings, Decision Inbox, Companies/Jobs Directory with S/A/B Tiers, Multi-Offer Comparison Matrix, Answer Bank, Agent Trace Auditing, and Career Timelines) accumulated across real campus recruiting workflows.

To prevent capability regressions and deliver a true production-grade Personal Career OS, the frontend must achieve 100% feature parity with all legacy functionality while upgrading the user experience to modern Vue 3 reactive SPA standards.

## What Changes

- **Workspace Dashboard & AI Briefing**: Port the legacy dashboard analytics, including AI Daily Briefing, 7-day stale application follow-up alarms, urgent deadline banners, and key recruitment KPI metrics.
- **Opportunities & Multi-Offer Comparison**: Migrate the complete Companies and Jobs directory (with Tier ratings, locations, industries, notes) and build the interactive Multi-Offer Comparison Matrix (salary, 12% provident fund, city living cost, commute/overtime ratings).
- **Decision Inbox & Human-In-The-Loop Governance**: Provide an interactive approval queue for newly sourced jobs by autonomous agents, allowing single-click or batch approval into the active application pipeline.
- **Answer Bank & Technical Defense Toolkit**: Implement the searchable knowledge base containing 30+ technical defense answers (MPC vs PID, PEEK CFD turbulence modeling, EKF state estimation) and real project interview scripts.
- **Agent Trace Logs & Auditing**: Render interactive, foldable execution trees detailing every background search, matching evaluation, and decision trace generated by Hermes Agent.
- **Knowledge Base & Profile SSOT**: Implement comprehensive Profile and 3-Track Resume management views with PDF rendering, notes journal, and milestone timelines.

## Capabilities

### New Capabilities
- `dashboard-intelligence-suite`: Modernized dashboard view integrating AI Daily Briefings, stale application follow-up alarms, deadline countdowns, and real-time recruitment metrics.
- `opportunities-and-offer-comparator`: Full-featured company/job directory with Tier filtering and a multi-dimensional Offer decision matrix.
- `decision-inbox-governance`: Human-in-the-loop approval center for reviewing agent-discovered jobs before pipeline enrollment.
- `answer-bank-and-interview-toolkit`: Searchable technical question-and-answer repository for project defense, algorithm rationale, and interview preparation.
- `agent-trace-auditor`: Visual trace inspector rendering background agent execution timelines and decision provenance.
