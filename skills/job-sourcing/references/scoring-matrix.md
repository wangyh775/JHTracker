# 岗位采集与综合匹配打分规则 (Scoring Matrix & Matching Rules)

本规则融合自 `career-tracker/skills/job-sourcing-and-scoring`，针对国内高校校招、应届生与日常实习场景进行针对性适配。

---

## 1. 评分维度权重配置 (Scoring Breakdown)

综合匹配度评分采用分段加权制（满分 100 分），分值分布如下：

```
综合得分 (0~100) = 硬性条件 (50%) + 技能与项目契合度 (30%) + 软实力与内推价值 (20%)
```

### 1.1 硬性条件 (50% 权重，门槛过滤)
| 考核要素 | 评分规则 | 判定逻辑 |
|---|---|---|
| **毕业年份/届别** | 15% | 完全符合对应毕业年份（如 2026 届）得 15 分；若明确要求往届或指定年份且不匹配，直接淘汰（得 0 分并触发硬淘汰） |
| **学历门槛** | 15% | 满足或高于招聘要求（如要求本科，候选人为硕博）得 15 分；低于门槛扣减或淘汰 |
| **专业相关度** | 10% | 计算机、软件工程、电子信息、数学等强对口专业得 10 分；工科理工科得 7 分；完全无关得 2 分 |
| **目标地点匹配** | 10% | 岗位城市在候选人意向工作城市列表中得 10 分；支持远程/全国分配得 8 分；异地得 3 分 |

### 1.2 核心技能与技术栈契合度 (30% 权重)
| 考核要素 | 评分规则 |
|---|---|
| **必选核心技术栈 (Must-have)** | 20% (每个匹配命中词得 4-5 分，如 Python、FastAPI、React、SQLite、分布式系统) |
| **加分项/了解项 (Nice-to-have)** | 10% (如 LLM 应用开发、Agent 编排、网络爬虫、Docker) |

### 1.3 软实力、内推与企业背景 (20% 权重)
| 考核要素 | 评分规则 |
|---|---|
| **企业标签与国央企/大厂稳定性** | 10% (央企、国企、外企、一线大厂、专精特新重点扶持企业) |
| **内推码直达 / 专属通道** | 5% (具备可用专属内推码 `referral_code`，可直接跳过简历初筛或直通笔试) |
| **投递时效性 / 黄金窗口** | 5% (近 7 天新发布岗位得 5 分；7-30 天得 3 分；超过 60 天或已超截止日期得 0 分) |

---

## 2. 匹配度分级标准 (Tier Classification)

- **Tier 1 (Strong Match - 强烈推荐，得分 ≥ 85)**:
  - 硬性门槛完全符合；
  - 技能命中率 ≥ 80%；
  - 建议智能体行为：主动向用户推荐，默认调用 `job_feedback(action='ACCEPT')` 加入待投递板。
- **Tier 2 (Good Match - 良好推荐，70 ≤ 得分 < 85)**:
  - 硬性条件基本满足，技术栈有 1-2 项可迁移或待提升；
  - 建议智能体行为：列入推荐列表供用户审查，标注缺失技能点与弥补建议。
- **Tier 3 (Potential Match - 观察池，50 ≤ 得分 < 70)**:
  - 边缘匹配，可能地点或部分技能不完全匹配；
  - 仅在用户扩大检索范围或缺乏充足匹配岗位时提供。
- **Reject (不匹配，得分 < 50 或触发硬性淘汰)**:
  - 智能体直接调用 `job_feedback(action='REJECT')` 抑制该类特征，并在未来推荐中自动过滤。
